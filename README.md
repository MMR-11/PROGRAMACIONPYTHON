# REPOSITORIO-2026-PARA-PROYECTOS
## propósito
El propósito de este repositório es ir guardando todos los proyectos que voy creando y exámenes de una forma organizada y limpia, para que en un futuro, si necesito ver algun archivo que haya creado, tenerlo localizado. También me sirve para poder ver las modificaciones que voy haciendo por si me he equivocado en programar poder volver atras.
## Descripción
Este repositorio me servirá para poder ver las modificaciones que voy haciendo por si me he equivocado en programar poder volver atras y juntamente poder tener organizados mis proyectos para no tenerlos de manera aleatoria en el escritorio o por alguna otra aplicación. También github te permite guardar tus proyectos y poder seguirlos desde otro dispositivo, por lo tanto, si no acabas un proyecto y lo guardas en github, lo podrás seguir más tarde.
